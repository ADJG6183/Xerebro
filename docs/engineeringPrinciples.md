# Engineering Principles

Design for failure first.

Prefer deterministic systems over probabilistic systems.

Never trust external APIs.

Every AI decision must be explainable.

Every recommendation must be reproducible.

Optimize for user trust over model intelligence.

Background work should never block interaction.

Prefer event-driven architecture.

Prefer immutable data.

Prefer composition over coupling.

Make every subsystem independently testable.

If a feature cannot fail gracefully, it is not production-ready.
